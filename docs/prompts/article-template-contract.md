# Article Template Contract Prompt Source

Purpose: define reader-facing article structure without forcing one rigid template.

## Reader-Facing Order

1. Opening hook.
2. Golden quote block, added by platform formatter.
3. Table of contents, added by platform formatter.
4. Body sections.
5. References or source note when appropriate.
6. Recent posts and fixed footer, added by platform formatter.

## Markdown Rules

- H2/H3 headings belong to body content only.
- Do not create sections named "标题", "摘要", "标题 + 摘要", "目录预览", or "文章摘要".
- Diagram blocks must be valid `mermaid` blocks.
- Normal programming code remains fenced code.
- Image captions should be plain caption text after the image.
