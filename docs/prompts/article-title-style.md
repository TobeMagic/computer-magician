# Article Title Style Prompt Source

Purpose: guide title options without hard-coding one template for every series.

## General Pattern

- Prefer informative titles with a clear domain prefix when useful.
- Strong title shape: `【领域 | 具体对象】短钩子：展开句`.
- Hooks can be meme-like, but the title must still tell readers what they will get.
- If the user provides a confirmed title, use it exactly unless a platform length limit rejects it.

## Interview Series

- Example: `【AI面试八股文 Vol.3.6：长上下文】为什么大模型还停在 20万/100万 Token：算力、注意力与中间遗忘`
- Vol/topic numbering comes from the series entry, not from model invention.

## Product/Hot Topic

- Use the real news object, conflict, and reader curiosity.
- Avoid generic "为什么值得写" phrasing when the style calls for a sharper hook.
